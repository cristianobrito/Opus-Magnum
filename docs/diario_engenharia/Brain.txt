agora para comitar minha branch de estudos 
  1. criar a branch e mudar pra ela
     git checkout -b feature/nome-da-branch 
  
  2. trabalhar adicionar e commitar a vontade
     git add .
     git commit -m "comitar as mudaças"
         ex. de commit "featur: implementado localstorage kanban" 
  
  3. para salvar
     git push origin feature/nome-da-branch
